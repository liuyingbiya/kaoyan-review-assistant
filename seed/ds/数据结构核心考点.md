# 数据结构 · 核心考点框架

## 复杂度分析

时间复杂度看基本操作次数随规模 n 的增长量级，用大 O 表示，只保留最高阶项、忽略常数。
常见量级由小到大：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)。

空间复杂度看额外占用的辅助空间。递归算法要考虑调用栈深度，例如归并排序是 O(n)，快排平均 O(log n)。

## 线性表

顺序表支持随机访问，按下标取值 O(1)，但插入删除平均移动一半元素，为 O(n)。
链表查找 O(n)，但已知节点位置时插入删除 O(1)。双向链表便于删除给定节点，循环链表便于实现轮转。

## 栈与队列

栈是后进先出（LIFO），应用：括号匹配、表达式求值、函数调用、递归转非递归、DFS。
队列是先进先出（FIFO），应用：层序遍历、BFS、任务调度、缓冲区。

循环队列用数组实现，判空 front == rear；判满通常留一个空位，(rear + 1) % maxSize == front，以此避免与判空冲突。

## 树

三种遍历：前序（根左右）、中序（左根右）、后序（左右根），层序按层从上到下。

已知前序 + 中序、或后序 + 中序可以唯一确定一棵二叉树；但**前序 + 后序不能唯一确定**。

完全二叉树可用数组存储，下标 i 的左孩子是 2i、右孩子是 2i+1（从 1 开始编号）。

二叉搜索树（BST）中序遍历得到有序序列。查找平均 O(log n)，退化成链表时 O(n)。

平衡二叉树（AVL）通过旋转保持左右子树高度差不超过 1；红黑树用颜色约束实现近似平衡，插入删除旋转次数更少。

堆是完全二叉树，建堆 O(n)，插入与删除堆顶 O(log n)，常用于优先队列与堆排序。

## 图

存储：邻接矩阵适合稠密图，判断相邻 O(1)，空间 O(n²)；邻接表适合稀疏图，空间 O(n+e)。

遍历：DFS 用栈或递归，BFS 用队列。BFS 可求无权图的最短路径。

最小生成树：Prim 从点出发，适合稠密图，复杂度 O(n²)；Kruskal 从边出发 + 并查集判环，适合稀疏图，O(e log e)。

最短路径：Dijkstra 用于非负权单源最短路，O((n+e) log n)；Floyd 求所有点对最短路，O(n³)，允许负权但不能有负环。

拓扑排序用于有向无环图（DAG），每次输出入度为 0 的顶点；若输出顶点数少于总数，说明图中有环。

## 排序对比

冒泡、选择、插入都是 O(n²)；插入排序对基本有序的序列接近 O(n)。
希尔排序是插入排序的改进，平均约 O(n^1.3)。
快速排序平均 O(n log n)，最坏 O(n²)（已有序且取首元素为基准），平均空间 O(log n)，不稳定。
归并排序稳定，时间 O(n log n)，需要 O(n) 辅助空间。
堆排序时间 O(n log n)，空间 O(1)，不稳定。
计数排序、基数排序是非比较排序，数据范围有限时可做到线性时间。

稳定性记忆：稳定的有冒泡、插入、归并、基数；不稳定的有选择、希尔、快排、堆排序。
