# 图与查找 · 高频考点

## 图的遍历

深度优先（DFS）借助栈或递归，适合求连通分量、判断是否有环、拓扑排序。时间复杂度：邻接表 O(n+e)，邻接矩阵 O(n²)。

广度优先（BFS）借助队列，**能求出无权图的最短路径**，也能求最短经过边数。这是 BFS 与 DFS 的核心区别。

## 最小生成树

Prim：从任意顶点出发，每次选一条连接"已选集合"与"未选集合"的最小边。时间复杂度 O(n²)（邻接矩阵），适合**稠密图**。

Kruskal：把所有边按权值排序，依次加入，用并查集判断是否成环。时间复杂度 O(e log e)，适合**稀疏图**。

两者都是贪心算法，得到的最小生成树总权值相同，但树的形状可能不同。

## 最短路径

Dijkstra：单源、非负权、贪心 + 优先队列，O((n+e) log n)。**不能处理负权边**，因为贪心前提被破坏。

Floyd：所有点对，三重循环 O(n³)，可以处理负权但**不能有负环**。代码形式是在 k 这一维上做松弛。

Bellman-Ford：单源，可处理负权，O(n·e)，能检测负环。

## 拓扑排序

适用于有向无环图（DAG）。每次输出入度为 0 的顶点并删除它的出边。若最终输出顶点数少于总顶点数，说明图中有环。

应用：依赖关系调度、课程安排、编译顺序。

## 关键路径

AOE 网中，从源点到汇点的最长路径叫关键路径，其上活动为关键活动。方法：正向求事件最早发生时间 ve，逆向求最迟发生时间 vl，活动时间余量 d = vl - ve 为 0 的是关键活动。

## 查找

顺序查找 O(n)，对表结构无要求。

折半查找 O(log n)，要求**顺序存储且有序**，判定树高度为 ⌈log₂(n+1)⌉。

分块查找：块间有序、块内无序，平均复杂度介于顺序与折半之间。

B 树与 B+ 树用于磁盘索引：B 树每个节点既存关键字也存数据，B+ 树只有叶子存数据、叶子之间用链表连接，因此**范围查询更快**，这是数据库索引多用 B+ 树的原因。

哈希表：平均查找 O(1)。冲突处理有开放定址法（线性探测、二次探测）与链地址法。装填因子越大冲突越多，查找效率越低。
