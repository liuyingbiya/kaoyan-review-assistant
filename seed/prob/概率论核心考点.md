# 概率论与数理统计 · 核心考点框架

## 随机事件与概率

- 事件的关系与运算：并、交、差、对立、互不相容
- 概率的基本性质：P(A∪B) = P(A) + P(B) - P(AB)
- 条件概率：P(A|B) = P(AB) / P(B)
- 乘法公式、全概率公式、贝叶斯公式
  - 全概率公式：按"原因"把样本空间分割，再求和
  - 贝叶斯公式：已知结果反推原因，是"逆概率"
- 事件的独立性：P(AB) = P(A)P(B)；注意**两两独立不等于相互独立**

## 一维随机变量及其分布

- 分布函数 F(x) = P(X ≤ x)，性质：单调不减、右连续、F(-∞)=0、F(+∞)=1
- 离散型：分布律
- 连续型：概率密度 f(x)，注意密度不是概率，且 f(x) 可以大于 1
- 常见分布要熟记：
  - 0-1 分布、二项分布 B(n,p)、泊松分布 P(λ)
  - 均匀分布 U(a,b)、指数分布 E(λ)、正态分布 N(μ,σ²)
- 随机变量函数的分布：分布函数法（先求 F 再求导），注意分段讨论

## 二维随机变量

- 联合分布函数、联合分布律、联合概率密度
- 边缘分布：对另一个变量求和/积分
- 条件分布：在给定一个变量取值的条件下
- 独立性：f(x,y) = f_X(x) f_Y(y)
- 两个随机变量函数的分布：和的分布（卷积公式）、最值的分布

## 数字特征

- 数学期望：E(X)，离散用求和、连续用积分；性质 E(aX+b) = aE(X)+b
- 方差：D(X) = E(X²) - [E(X)]²；D(aX+b) = a²D(X)
- 常见分布的期望与方差要背熟
- 协方差与相关系数：Cov(X,Y) = E(XY) - E(X)E(Y)；ρ 的绝对值 ≤ 1
- 不相关与独立：**独立一定不相关，不相关不一定独立**（正态分布是例外）

## 大数定律与中心极限定理

- 切比雪夫不等式：给出偏离均值的概率上界
- 大数定律：样本均值依概率收敛到总体均值
- 中心极限定理：大量独立同分布随机变量之和近似服从正态分布 —— 这是"为什么很多现象可以用正态分布建模"的理论依据

## 数理统计

- 总体、样本、统计量
- 常用抽样分布：χ² 分布、t 分布、F 分布，以及它们的构造方式
- 参数估计：
  - 矩估计：用样本矩替换总体矩
  - 最大似然估计：写似然函数 → 取对数 → 求导令零 → 解出参数
  - 估计量的评价标准：无偏性、有效性、一致性
- 区间估计：置信区间的含义是"重复抽样时约 95% 的区间会包含真值"，不是"真值有 95% 概率落在这个区间里"
- 假设检验：原假设与备择假设、两类错误（弃真 / 取伪）、显著性水平

## 学习建议

1. 概率论的概念性很强，"不相关不等于独立""密度不是概率"这类反直觉点是高频陷阱。
2. 常见分布的期望方差必须条件反射式地写出来。
3. 二维部分要会画积分区域，这是数一概率大题的常见形式。
4. 数理统计偏记忆，但最大似然估计的计算必须练熟。
