# 线性代数 · 常见题型套路

## 一、求矩阵的秩

方法：初等**行**变换化为行阶梯形，非零行的行数就是秩。

常用结论：
- r(AB) ≤ min{r(A), r(B)}
- r(A+B) ≤ r(A) + r(B)
- A 为 m×n 矩阵，r(A) = n（列满秩）时 Ax=0 只有零解
- r(A) = n 的 n 阶矩阵可逆

## 二、解线性方程组

齐次 Ax = 0：
- r(A) = n → 只有零解
- r(A) < n → 有非零解，基础解系含 n - r(A) 个向量

非齐次 Ax = b：
- 先看 r(A) 与 r(A|b)：不等则**无解**（这是最容易忽略的一步）
- r(A) = r(A|b) = n → 唯一解
- r(A) = r(A|b) < n → 无穷多解，通解 = 特解 + 齐次通解

解题步骤固定：写增广矩阵 → 行变换化阶梯形 → 读秩 → 判断解的情况 → 写出自由未知量 → 给基础解系。

## 三、求特征值与特征向量

解特征方程 |λE - A| = 0 得特征值；对每个特征值解 (λE - A)x = 0 得特征向量。

常用性质：
- 特征值之和 = 矩阵的迹（主对角线元素之和）
- 特征值之积 = 行列式
- 不同特征值对应的特征向量线性无关

## 四、判断能否对角化

充要条件：A 有 n 个线性无关的特征向量。

充分条件：
- n 个特征值互不相同 → 一定可对角化
- **实对称矩阵一定可以正交对角化**

判定"不可对角化"的典型情形：某特征值的代数重数大于其几何重数（即 λE-A 的秩不够小）。

## 五、实对称矩阵与正定性

正定矩阵的判定（任选其一）：
- 顺序主子式全大于 0
- 特征值全大于 0
- 与单位矩阵合同

半正定：特征值全 ≥ 0。

二次型化标准形：配方法或正交变换。用正交变换时，标准形系数就是特征值。

## 六、易错点

- 初等变换只能用**行**变换求秩和解方程组；求特征值不能随便做行变换（会改变特征值）
- 矩阵乘法不满足交换律，AB ≠ BA
- 分块矩阵求逆要注意块的顺序
- 逆矩阵存在的充要条件是行列式不为零
