# 线性代数 · 核心考点框架

线性代数的特点是**概念之间高度关联**，孤立背定义会越学越乱。建议按一条主线串起来：
行列式 → 矩阵 → 向量组 → 线性方程组 → 特征值 → 二次型。

## 行列式

- 定义与性质：交换两行变号、某行乘 k 则行列式乘 k、某行加上另一行的 k 倍不变
- 展开定理：按行或按列展开，配合代数余子式
- 常见特殊行列式：上三角、范德蒙德、爪型、箭型
- 应用：判断矩阵可逆、求逆矩阵的伴随矩阵法、克拉默法则

## 矩阵

- 运算：加法、数乘、乘法（**不满足交换律**）、转置、求逆
- 逆矩阵：可逆的充要条件是行列式不为零；求法有伴随矩阵法和初等行变换法
- 初等变换与初等矩阵：左乘初等矩阵相当于行变换，右乘相当于列变换
- 秩：矩阵的秩等于其非零子式的最高阶数，也等于行（列）向量组的极大无关组所含向量个数
- 分块矩阵：分块对角矩阵的逆与行列式最容易考

## 向量组

- 线性相关与线性无关的定义：存在不全为零的系数使线性组合为零，则相关
- 判定：向量个数大于维数必相关；秩小于向量个数则相关
- 极大线性无关组与秩：秩 = 极大无关组中向量个数
- 等价向量组：可以相互线性表示

## 线性方程组

这是线代的核心，几乎每年必考。

- 齐次方程组 Ax = 0：总有零解；有非零解的充要条件是 r(A) < n（未知数个数）；基础解系含 n - r(A) 个向量
- 非齐次方程组 Ax = b：有解的充要条件是 r(A) = r(A|b)；此时若 r = n 有唯一解，若 r < n 有无穷多解
- 通解 = 特解 + 对应齐次方程组的通解
- 解题套路：对增广矩阵做初等**行**变换化为行阶梯形 → 读出秩 → 判断解的情况 → 写出基础解系

## 特征值与特征向量

- 定义：Ax = λx，x 非零
- 特征多项式 |λE - A| = 0 求特征值
- 性质：特征值之和等于矩阵的迹，特征值之积等于行列式
- 相似对角化：A 可对角化的充要条件是 A 有 n 个线性无关的特征向量
  - 若 A 有 n 个互不相同的特征值，必可对角化
  - 实对称矩阵一定可以正交对角化（这是很重要的结论）
- 应用：求 A^n（对角化后 λ^n）

## 二次型

- 二次型的矩阵表示：f = x^T A x，A 为实对称矩阵
- 合同变换与配方法化标准形
- 正定性判别：
  - 顺序主子式全大于零
  - 或特征值全大于零
- 惯性定理：标准形中正、负项个数由秩与符号差决定，与变换方式无关

## 学习建议

1. 每学完一块，立刻回去看**它和前面有什么关系**。比如秩贯穿了矩阵、向量组、方程组、二次型。
2. 计算能力是线代的命门。行列式计算、初等变换、求逆、求特征值，都要练到不出错。
3. 证明题主要集中在：线性相关性的证明、秩的不等式、可对角化的判定。
