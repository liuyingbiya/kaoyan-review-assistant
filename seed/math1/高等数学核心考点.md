# 高等数学 · 核心考点框架

## 极限与连续

极限是整门课的地基。常考：
- 等价无穷小替换（只能在**乘除因子**里换，加减里换容易出错）
- 洛必达法则（只有 0/0、∞/∞ 型才能用，且要求导数存在）
- 泰勒展开（比洛必达更适合多次求导仍不定的情况）
- 夹逼准则（n 项和求极限常用）
- 两个重要极限：sin x / x → 1，以及 (1 + 1/x)^x → e

连续的三要素：函数在该点有定义、极限存在、极限值等于函数值。间断点分第一类（可去、跳跃）和第二类（无穷、振荡）。

## 导数与微分

- 可导必连续，连续不一定可导（如 y = |x| 在 0 点）
- 高阶导数、隐函数求导、参数方程求导
- 微分中值定理：罗尔、拉格朗日、柯西、泰勒。证明题几乎每年考，**关键是构造辅助函数**
- 单调性与极值：一阶导数为零的点是驻点，还要判断两侧符号变化
- 凹凸性与拐点：二阶导数符号
- 渐近线：水平、垂直、斜渐近线三种，斜渐近线用 y = kx + b 求

## 一元积分

- 不定积分：换元法（第一类凑微分、第二类三角代换）、分部积分（反对幂指三的顺序选 u）
- 定积分：牛顿-莱布尼茨公式、换元要换上下限、对称区间上的奇偶性化简
- 反常积分：无穷区间与无界函数两类，注意收敛性判断
- 定积分的应用：面积、旋转体体积、弧长、物理应用

## 多元函数微分

- 偏导数、全微分、链式法则
- 隐函数求导（公式法或两边求导）
- 极值与条件极值：无条件极值用 Hessian 判别，条件极值用拉格朗日乘数法
- 方向导数与梯度

## 多元积分

- 二重积分：直角坐标下的 X 型/Y 型区域、极坐标变换（圆形区域或含 x²+y² 时用）
- 三重积分：先一后二、先二后一、柱面坐标、球面坐标
- 曲线积分：第一类（对弧长）与第二类（对坐标），格林公式联系两者的关系
- 曲面积分：高斯公式、斯托克斯公式
- 对称性化简是这几块的通法，能大幅减少计算量

## 无穷级数

- 正项级数判敛：比较、比值、根值
- 交错级数：莱布尼茨判别法
- 幂级数：收敛半径求法、和函数（逐项求导/积分）
- 傅里叶级数：数一考，注意周期延拓与收敛定理

## 微分方程

- 一阶：可分离变量、齐次、一阶线性（公式法）
- 高阶：可降阶的三类、二阶常系数线性（齐次特征方程、非齐次待定系数法）
